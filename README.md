# MyDatingProfileHelper

## Помощник в создании анкеты для сайтов знакомств

MyDatingProfileHelper - это Android приложение, разработанное для помощи пользователям в создании привлекательных анкет для сайтов знакомств. Приложение позволяет пользователям создать подробный профиль, включающий интересы, фотографии, цели знакомства и текстовое описание. Предусмотрена интеграция с Google для входа и резервного копирования данных.

## Текущий статус

На данный момент реализованы следующие компоненты:

*   **Базовая структура проекта:** Созданы основные папки, настроены зависимости в `build.gradle` и создан базовый `AndroidManifest.xml`.
*   **Вход через Google:** Реализована базовая функциональность входа в приложение с использованием аккаунта Google.
*   **Модель профиля пользователя:** Определена структура данных для хранения информации профиля пользователя (`UserProfile.kt`).
*   **Репозиторий пользователя:** Создан класс `UserRepository.kt` для управления данными профиля пользователя. В нем предусмотрены заглушки для сохранения и загрузки данных, включая интеграцию с Google Drive.
*   **Заглушки API:** Созданы интерфейсы и базовые реализации-заглушки для взаимодействия с бэкендом (`DatingProfileApi`, `DatingProfileApiService`) для получения примеров описаний и нейросетями (`NeuralNetworkApi`, `NeuralNetworkApiService`) для генерации или улучшения текста.

## Следующие шаги
*   **Создание базовых экранов:** Реализованы базовые экраны приложения (Профиль, Главная, Карточки) с использованием фрагментов.
*   **Навигация:** Настроена базовая навигация между основными экранами с использованием BottomNavigationView.
*   **Реализация базового UI:** Добавлена базовая реализация пользовательского интерфейса для экранов Профиль, Главная и Карточки. Для отображения списков используется `RecyclerView` (на главной странице), а для карточек предусмотрены элементы-заглушки. Элементы UI связаны с соответствующими ViewModel для отображения данных и обработки пользовательских действий.

*   **Интеграция API заглушек и UI:** Заглушки API интегрированы с `UserRepository`, который связан с UI слоем через ViewModel. Каждый основной экран имеет свой ViewModel (`ProfileViewModel`, `HomeViewModel`, `CardsViewModel`), который управляет данными, связанными с UI, и взаимодействует с `UserRepository`. ViewModel помогает отделить логику работы с данными от пользовательского интерфейса и обеспечивает сохранение данных при изменении конфигурации экрана.

*   **Механизм кристаллов и подготовка к оплате:** Добавлена базовая реализация механизма местной валюты (кристаллы) в `UserRepository` и `ProfileViewModel`. Созданы заглушки (`PaymentGateway`, `TelegramPaymentService`) для будущей интеграции с платежными системами, включая оплату через Telegram. Отмечено, что полная реализация оплаты требует взаимодействия с бэкендом и API Telegram Bot API.

## Структура проекта

Проект организован по слоям:
*   **UI:** Содержит Activity и Fragments, отвечающие за отображение пользовательского интерфейса. Использует ViewModel для взаимодействия с данными.
*   **Activity:** Выступает в роли контейнера для фрагментов и управляет навигацией между основными экранами (например, `BottomNavigationActivity`).
*   **Fragments:** Представляют собой отдельные экраны или части пользовательского интерфейса (например, `ProfileFragment`, `HomeFragment`, `CardsFragment`).
