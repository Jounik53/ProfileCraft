# MyDatingProfileHelper

## Помощник в создании анкеты для сайтов знакомств

MyDatingProfileHelper - это Android приложение, разработанное для помощи пользователям в создании привлекательных анкет для сайтов знакомств. Приложение позволяет пользователям создать подробный профиль, включающий интересы, фотографии, цели знакомства и текстовое описание. Предусмотрена интеграция с Google для входа и резервного копирования данных.

## Текущий статус

На данный момент реализованы следующие компоненты:

*   **Базовая структура проекта:** Созданы основные папки, настроены зависимости в `build.gradle` и создан базовый `AndroidManifest.xml`.
*   **Вход через Google:** Реализована базовая функциональность входа в приложение с использованием аккаунта Google.
*   **Модель профиля пользователя:** Определена структура данных для хранения информации профиля пользователя (`UserProfile.kt`).
*   **Репозиторий пользователя:** Создан класс `UserRepository.kt` для управления данными профиля пользователя. В нем предусмотрены заглушки для сохранения и загрузки данных, включая интеграцию с Google Drive.
*   **Заглушки API:** Созданы интерфейсы и базовые реализации-заглушки для взаимодействия с бэкендом (`DatingProfileApi`, `DatingProfileApiService`) для получения примеров описаний и нейросетями (`NeuralNetworkApi`, `NeuralNetworkApiService`) для генерации или улучшения текста.

## Следующие шаги
*   **Создание базовых экранов:** Реализованы базовые экраны приложения (Профиль, Главная, Карточки) с использованием фрагментов.
*   **Навигация:** Настроена базовая навигация между основными экранами с использованием BottomNavigationView.
*   **Реализация базового UI:** Добавлена базовая реализация пользовательского интерфейса для экранов Профиль, Главная и Карточки. Для отображения списков используется `RecyclerView` (на главной странице), а для карточек предусмотрены элементы-заглушки. Элементы UI связаны с соответствующими ViewModel для отображения данных и обработки пользовательских действий.

*   **Интеграция API заглушек и UI:** Заглушки API интегрированы с `UserRepository`, который связан с UI слоем через ViewModel. Каждый основной экран имеет свой ViewModel (`ProfileViewModel`, `HomeViewModel`, `CardsViewModel`), который управляет данными, связанными с UI, и взаимодействует с `UserRepository`. ViewModel помогает отделить логику работы с данными от пользовательского интерфейса и обеспечивает сохранение данных при изменении конфигурации экрана.

*   **Механизм кристаллов и подготовка к оплате:** Добавлена базовая реализация механизма местной валюты (кристаллы) в `UserRepository` и `ProfileViewModel`. Созданы заглушки (`PaymentGateway`, `TelegramPaymentService`) для будущей интеграции с платежными системами, включая оплату через Telegram. Отмечено, что полная реализация оплаты требует взаимодействия с бэкендом и API Telegram Bot API.

## Структура проекта

Проект организован по слоям:
*   **UI:** Содержит Activity и Fragments, отвечающие за отображение пользовательского интерфейса. Использует ViewModel для взаимодействия с данными.
*   **Activity:** Выступает в роли контейнера для фрагментов и управляет навигацией между основными экранами (например, `BottomNavigationActivity`).
*   **Fragments:** Представляют собой отдельные экраны или части пользовательского интерфейса (например, `ProfileFragment`, `HomeFragment`, `CardsFragment`).

## Сборка и запуск проекта

Для сборки и запуска проекта MyDatingProfileHelper вам потребуется следующая среда разработки:

### Необходимое программное обеспечение

*   **Android Studio:** Интегрированная среда разработки (IDE) для создания приложений на платформе Android. Рекомендуется использовать последнюю стабильную версию.
    *   [Скачать Android Studio](https://developer.android.com/studio)
*   **Java Development Kit (JDK):** Для компиляции Java и Kotlin кода. Android Studio обычно поставляется сbundled JDK, но убедитесь, что у вас установлена совместимая версия (рекомендуется OpenJDK).
*   **Android SDK:** Набор инструментов разработки для Android. Убедитесь, что у вас установлена SDK Platform для Android API 34 (Android 14) или выше. SDK Components можно установить через SDK Manager в Android Studio.
*   **Git:** Система контроля версий для клонирования репозитория проекта.
    *   [Скачать Git](https://git-scm.com/downloads)

### Шаги по сборке и запуску

1.  **Клонирование репозитория:**
    Откройте терминал или командную строку и выполните следующую команду, чтобы клонировать репозиторий проекта:
    Замените `<URL вашего репозитория>` на фактический URL репозитория проекта.

2.  **Открытие проекта в Android Studio:**
    *   Запустите Android Studio.
    *   Выберите "Open an existing Android Studio project".
    *   Перейдите в папку, куда вы клонировали репозиторий (MyDatingProfileHelper), и выберите корневую папку проекта.

3.  **Синхронизация проекта с файлами Gradle:**
    После открытия проекта Android Studio автоматически начнет синхронизацию проекта с файлами Gradle. Дождитесь завершения этого процесса. Если синхронизация не началась автоматически, выберите "File" -> "Sync Project with Gradle Files" в меню Android Studio.

4.  **Настройка Google Sign-In:**
    *   Для работы входа через Google вам потребуется настроить проект в Google Cloud Console и получить файл `google-services.json`. Следуйте инструкциям Google по добавлению Google Sign-In в ваше Android приложение: [Добавление Google Sign-In в приложение Android](https://developers.google.com/identity/sign-in/android/start-integrating)
    *   Поместите файл `google-services.json` в директорию `app/`.

5.  **Настройка Google Drive API:**
    *   Для работы с Google Drive API вам также потребуется включить Google Drive API в Google Cloud Console и настроить соответствующие учетные данные. Следуйте инструкциям Google по работе с Google Drive API в Android: [Начало работы с Google Drive API для Android](https://developers.google.com/drive/android/intro)

6.  **Выбор целевого устройства:**
    *   Подключите физическое устройство Android к компьютеру (убедитесь, что включен режим отладки по USB) или
    *   Создайте и запустите эмулятор Android Virtual Device (AVD) через AVD Manager в Android Studio. Убедитесь, что эмулятор использует образ системы с API 34 или выше.

7.  **Запуск приложения:**
    *   Выберите целевое устройство (подключенное устройство или запущенный эмулятор) из выпадающего списка на панели инструментов Android Studio.
    *   Нажмите кнопку "Run" (зеленый треугольник) на панели инструментов или выберите "Run" -> "Run 'app'" в меню.

Android Studio соберет проект, установит приложение на выбранное устройство и запустит его.

### Тестирование

После успешного запуска приложения вы можете провести ручное тестирование, чтобы проверить базовую функциональность:

*   **Вход через Google:** Проверьте, работает ли вход с использованием вашего Google аккаунта.
*   **Навигация:** Убедитесь, что нижнее меню позволяет переключаться между экранами Профиль, Главная, Карточки и Настройки.
*   **Экран Профиля:** Проверьте, отображаются ли элементы UI для профиля и можно ли вводить данные. (Обратите внимание, что сохранение и загрузка данных через Google Drive пока реализованы как заглушки).
*   **Главная страница:** Проверьте, отображается ли `RecyclerView` (пустой или с заглушечными данными из `DatingProfileApiService`).
*   **Экран Карточек:** Проверьте, отображаются ли элементы UI для карточек (пустые или с заглушечными данными).
*   **Настройки:** Проверьте, работают ли переключатели языка, выбора API нейросетей и темы. Посмотрите, изменяется ли язык и тема приложения.

Для более полного тестирования в будущем потребуется реализовать автоматические тесты:

*   **Unit-тесты:** Для проверки логики ViewModel и UserRepository без зависимостей от Android фреймворка.
*   **Интеграционные тесты:** Для проверки взаимодействия между компонентами (например, UserRepository с API заглушками или Google Drive API).
*   **UI-тесты (Espresso):** Для тестирования пользовательского интерфейса и взаимодействия пользователя с экранами.
